## 2. Components

Click 'Add Component' button

![alt text](m6.png)

user can choose Category\Component Type\Device Type\Icon  and fill in Name\ Unique Name and Description in first page

![alt text](m7.png)

If User select special device type, user have to fill in neccessary device infomation in second page to connect device.

![alt text](m8.png)

![alt text](m9.png)

For Consumer type components，there is a 'Record Consumption Data' button, if enables it, the cosumption will add into All Consumption by clicking 'Reporting'

For other types components, there is a 'Controllability Of Component' button, if enables it, user can select priority, and system will controll the component

![alt text](m10.png)

Right-click a component, user can edit or delete the component.

![alt text](m11.png)

Click 'Edit' button, user can modify all info except Category and Component Type

![alt text](m12.png)

Click 'Sync' button, if component sync into VC Hub successfully, there will a prompt 

![alt text](m13.png)

Click component, component's detail page will display. 

The General column will show all kinds of information about the component. Click the edit button to modify it, and click the delete button to remove the component. When the component is connected to a real device, you can check various parameters in the consumer parameter column.

![alt text](m15.png)

For Charging Infrastructure (WALM), Consumption Meter and Battery Storage components, there will be an extra column for the control parameter
    
![alt text](m14.png)


## 3. Subgroups

Click 'Subgroups' tab, click 'Add Subgroups' button, user can create different subgroup by selecting types

![alt text](m16.png)

Fill in all kinds info, click 'Next' button, user can select existed components. 

When the subgroup type is Energy Meter, an extra Subgroup field appears so that the user can select a sub-subgroup.

![alt text](m17.png)

After selecting components or subgroups, click 'Next' button, user can select indicator for Subgroup.

![alt text](m18.png)

Right-click a subgroup, user can edit or delete the subgroup.

![alt text](m19.png)
